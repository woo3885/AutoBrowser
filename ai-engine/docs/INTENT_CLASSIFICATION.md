# 금융 업무 Intent 분류 체계

> **규칙 기반 보조 분류기:** 이 문서는 `src/intents` 구현을 설명합니다. Chrome Extension의 대화 판단은 이 분류만으로 고정 시나리오를 선택하지 않고 Gemini와 최신 정제 DOM을 함께 사용합니다.

## 목적

사용자의 금융 업무 요청을 분석하여 AI Engine이 수행해야 할 업무 유형을 결정한다.

## Intent 목록

| Intent   | 설명                         |
| -------- | -------------------------- |
| DEPOSIT  | 예금, 적금, 저축 상품 탐색 및 가입      |
| TRANSFER | 계좌이체, 송금, 자동이체 관련 업무       |
| INQUIRY  | 잔액, 거래내역, 계좌정보 조회          |
| CHANGE   | 비밀번호, 이체 한도, 개인정보 및 설정 변경  |
| RISK     | 보이스피싱, 금융사기, 분실, 해킹, 의심 거래 |
| UNKNOWN  | 분류할 수 없거나 정보가 부족한 요청       |

## 분류 정책

1. 사용자 문장의 앞뒤 공백과 내부 공백을 제거한다.
2. 문장을 소문자로 변환하여 정규화한다.
3. Intent별 등록 키워드와 사용자 문장을 비교한다.
4. 일치하는 키워드 수를 기준으로 Intent 점수를 계산한다.
5. 위험 관련 키워드가 감지되면 RISK Intent에 우선 가중치를 부여한다.
6. 일치하는 키워드가 없으면 UNKNOWN으로 분류한다.
7. UNKNOWN 결과는 사용자의 목적을 확인하기 위한 추가 질문으로 처리한다.

## 위험 Intent 우선 정책

금융 위험과 관련된 요청은 일반적인 금융 업무보다 우선 처리한다.

예시:

* 모르는 사람이 송금을 요구해요.
* 사기 계좌로 이체한 것 같아요.
* 보이스피싱을 당한 것 같아요.
* 카드를 잃어버렸어요.
* 계좌가 해킹된 것 같아요.

위 문장에 송금, 이체, 계좌 등의 일반 업무 키워드가 포함되더라도 위험 키워드가 감지되면 RISK로 분류한다.

## Intent별 후속 동작

| Intent   | 예상 후속 동작            |
| -------- | ------------------- |
| DEPOSIT  | 예금·적금 상품 메뉴 탐색      |
| TRANSFER | 계좌이체·송금 메뉴 탐색       |
| INQUIRY  | 잔액·거래내역·계좌정보 메뉴 탐색  |
| CHANGE   | 설정·인증·개인정보 변경 메뉴 탐색 |
| RISK     | 자동 행동 중지 및 보안 안내    |
| UNKNOWN  | 사용자에게 추가 질문         |

## 현재 구현 방식

현재 Intent 분류는 규칙 기반 키워드 방식으로 구현되어 있다.

분류 결과에는 다음 정보가 포함된다.

```json
{
  "intent": "RISK",
  "confidence": 0.9,
  "matchedKeywords": ["모르는 사람", "불안"],
  "reason": "RISK 관련 키워드가 감지되었습니다."
}
```

## 향후 개선 방향

* Gemini 기반 보조 Intent 분류
* 키워드가 없는 자연어 표현 처리
* 복수 Intent 감지
* Intent 충돌 처리
* 팀 시나리오 기반 테스트 케이스 확대
* 금융기관별 메뉴 표현 차이 반영
