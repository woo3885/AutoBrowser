# 금융길잡이 AI 자동화 보안 정책

> **현재 적용 범위(2026-09-14):** 정책 판단은 AI Engine과 Backend에서, 마지막 실행 차단은 Chrome Extension의 Content Script에서도 적용합니다. 레거시 Viewer 관련 표현보다 [현재 아키텍처](../CURRENT_ARCHITECTURE.md)를 우선합니다.

## 1. 기본 원칙

금융길잡이 AI는 사용자의 금융업무를 보조하지만, 사용자를 대신해 중요한 금융 의사결정을 내리지 않는다.

AI는 화면 분석과 일반적인 브라우저 조작을 수행할 수 있으나, 금융상품 선택과 최종 거래 실행은 사용자가 직접 결정해야 한다.

## 2. 사용자 결정이 필요한 항목

AI는 다음 항목을 임의로 선택하지 않는다.

- 금융상품 선택
- 계좌 선택
- 수취인 선택
- 납입 금액 및 이체 금액 확정
- 선택 약관 동의
- 마케팅 정보 수신 동의
- 개인정보 제3자 제공 동의
- 최종 금융거래 실행

필수 약관과 선택 약관은 구분하여 사용자에게 제공해야 한다.

선택 약관과 마케팅 동의는 자동으로 선택하지 않는다.

## 3. 민감정보 처리

다음 정보는 민감정보로 분류한다.

- 로그인 비밀번호
- PIN
- 인증번호
- 보안카드 정보
- OTP 값
- 주민등록번호
- 카드번호
- 계좌 인증정보
- 공동인증서 비밀번호

민감정보는 사용자가 직접 입력한다.

백엔드는 보안 입력을 전달하기 위한 통신 경로를 제공할 수 있으나 다음 원칙을 준수해야 한다.

- AI 모델에 전달하지 않는다.
- 화면 분석 데이터에 포함하지 않는다.
- DOM 수집 결과에 포함하지 않는다.
- 로그에 저장하지 않는다.
- 화면 캡처에 포함하지 않는다.
- 오류 메시지에 원문을 포함하지 않는다.

## 4. 보안 입력 모드

민감정보 입력이 필요한 경우 상태를 다음과 같이 변경한다.

`SECURE_INPUT_REQUIRED`

보안 입력 모드에서는 다음 기능을 일시 중지한다.

- AI 실행
- DOM 캡처
- 스크린샷 저장
- 브라우저 입력값 기록
- 요청 및 응답 본문 로깅

보안 입력이 완료되면 실제 값이 아닌 완료 여부만 기록한다.

## 5. 최종 확인 정책

다음 작업은 사용자의 최종 확인 없이 실행하지 않는다.

- 송금
- 계좌 개설
- 예금 또는 적금 가입
- 투자상품 가입
- 대출 신청
- 자동이체 등록
- 결제 확정
- 개인정보 제공 동의

최종 확인이 필요한 경우 상태를 다음과 같이 변경한다.

`FINAL_CONFIRMATION_REQUIRED`

사용자가 명시적으로 승인한 이후에만 최종 버튼을 실행한다.

## 6. 브라우저 자동화 제한

AI가 제안한 브라우저 행동은 백엔드에서 검증한 후 실행한다.

허용된 행동 유형 외의 명령은 실행하지 않는다.

다음 동작은 검증 없이 실행하지 않는다.

- 외부 도메인 이동
- 파일 다운로드
- 파일 업로드
- 결제 및 송금
- 약관 전체 자동 동의
- 보안정보 입력
- 브라우저 스크립트 직접 실행

## 7. 로그 정책

로그에 다음 정보를 저장하지 않는다.

- 비밀번호
- 인증번호
- OTP
- 보안카드 값
- 주민등록번호
- 카드번호
- 계좌번호 전체 값
- 인증서 정보
- 민감한 DOM 값

식별이 필요한 경우 일부 값만 마스킹하여 기록한다.

예시:

```text
계좌번호: 123-***-***789
카드번호: 1234-****-****-5678
```

## 8. 세션 종료 정책

다음 상황에서는 자동화 세션을 종료한다.

- 작업 완료
- 사용자 취소
- 일정 시간 동안 응답 없음
- 치명적인 자동화 오류
- 보안 정책 위반
- 허용되지 않은 도메인 접근

세션 종료 시 다음 데이터를 정리한다.

- 브라우저 인스턴스
- 임시 DOM 데이터
- 임시 스크린샷
- 세션 토큰
- 보안 입력 상태
- 임시 캐시

## 9. 오류 처리

오류 발생 시 사용자에게 이해 가능한 메시지를 제공한다.

내부 시스템 경로, 스택 트레이스, 민감정보는 사용자 응답에 노출하지 않는다.

보안 관련 오류가 발생하면 자동화를 즉시 중단하고 상태를 `ERROR` 또는 `TERMINATED`로 변경한다.
